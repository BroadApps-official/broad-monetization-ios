# Как предложить изменение

Repository и документация публичны. Любой разработчик может сделать fork,
создать branch и открыть pull request.

Не добавляйте `BroadUIFlows`/`BroadExtensions`, app-owned IDs/secrets, real
payment operations и test targets. Обновите docs/sandbox/probes/API
report/changelog, выполните `bash Scripts/module_gate.sh` и объясните в PR,
что изменилось и почему.
